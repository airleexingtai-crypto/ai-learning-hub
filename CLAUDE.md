# AI Learning Website

## Project
AI tutorial blog monetized via SEO traffic + Google AdSense.
Target audience: developers and everyday users learning AI tools.

## Design (see DESIGN.md for full spec)
- Content-driven blog, readability first
- Warm Editorial style: Source Serif 4 (headings) + Inter (body)
- Clean, professional, trustworthy visual identity
- SEO/GEO friendly: semantic HTML, structured data, fast load
- Mobile-first, Core Web Vitals compliant
- All public-facing UI copy in English (global audience)

## Installed Design Skills
These skills auto-apply on all UI/visual decisions:
- `web-design` — spec-first: DESIGN.md → code
- `impeccable` — 23 design commands (audit/polish/colorize/animate etc.)
- `taste-skill` — anti-slop, configurable design parameters
- `minimalist-ui` — editorial UI, ideal for blogs
- `make-interfaces-feel-better` — micro-interaction polish

## Installed Writing Skills
These skills auto-apply on all article content creation and editing:
- `humanizer` — 24 AI writing patterns (Wikipedia-based), two-pass rewrite+audit, soul injection
- `avoid-ai-writing` — 36 pattern categories, 109-entry tiered replacement table, detect/rewrite dual mode

## Tech Stack
- Next.js 14+ (App Router) + TypeScript + Tailwind CSS
- MDX for articles
- Vercel deployment

## Language
- All public-facing UI copy and article content: English
- Code comments: English
- Conversations with user: Chinese
